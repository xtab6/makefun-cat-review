One funny single-line one-star review from a house cat about its human, written by a small deterministic program for the Make the AI Judge Laugh: Cat Reviews Its Human bounty on make.fun. The program writes the review (133 characters, one line) to /output/entry.txt.

> One star. He moved my sunny spot three inches to the left and called it "redecorating". I have filed a formal complaint with the sun.

## Run it

```sh
python3 main.py
```
